# UMD — Universal Media Downloader

Windows x64 приложение для загрузки медиафайлов и обработки метаданных.
Beta 2 версии `0.1.0` добавляет GUI на Qt, анализ ссылок и постоянную очередь.

## Запуск

1. Скачайте portable ZIP со страницы [Releases](https://github.com/omphkind/UMD/releases).
2. Распакуйте **весь** архив и запустите `UMD/UMD.exe`.
3. Вставьте URL и нажмите **Анализировать**. Выберите тип, доступное качество,
   контейнер, субтитры и каталог, затем **Добавить в очередь**.

Python, Qt, yt-dlp, FFmpeg/FFprobe, Deno и Chromium входят в сборку.
Системная установка не нужна. Windows 10/11 x64; подписания EXE пока нет.
Настройки, очередь, прогресс и логи: `%LOCALAPPDATA%\UMD`.
Папка загрузок по умолчанию: `%LOCALAPPDATA%\UMD\output`.

## Загрузка и очередь

- Источник определяется extractor-ом yt-dlp. Поддержка конкретной ссылки зависит
  от доступности ресурса и установленной версии yt-dlp; список сервисов не ограничен вручную.
- Видео, аудио, субтитры, обложка или только метаданные. Качества и языки
  показываются по результату анализа. Подробный режим показывает codec, fps,
  bitrate, HDR, размер и format ID, когда эти сведения есть у источника.
- MP4/MKV/WebM/MOV; FFmpeg объединяет потоки и при необходимости конвертирует
  несовместимые кодеки. Аудио: исходный формат, MP3/M4A/Opus/WAV/FLAC.
- Авторские и автоматические субтитры: VTT/SRT/ASS. Обложки и главы сохраняются
  по выбору пользователя. Рядом с медиа сохраняется JSON метаданных.
- Каналы/плейлисты разворачиваются в отдельные задачи. Форматы каждого объекта
  проверяются перед загрузкой; если выбранного качества нет, задача сообщает ошибку.
- Пауза, продолжение, отмена, повтор ошибок; те же действия для всей очереди.
  Частичные загрузки сохраняются для продолжения. Отмена оставляет уже созданные файлы.
  Закрытие приложения сохраняет незавершённые задачи на паузе.
- Библиотека показывает готовые файлы; можно открыть папку или скопировать URL.
  «Убрать готовые» очищает записи очереди, сохраняя файлы на диске.

## Метаданные YouTube

Для совместимого экспорта MetaFin выберите **Только метаданные** после анализа
YouTube URL или используйте **История → Новая обработка**.
Несколько URL вводятся по одному в строке на экране загрузок.
В истории доступны продолжение, обновление источника и повтор только ошибок.

Оригинальные данные получаются через локальный yt-dlp; локализованные название
и описание — через анонимный Chromium с `ru-RU`. При сбое локализации используется
оригинал. Очистка описаний консервативная, исходный текст сохраняется в JSON.
Shorts и Members-only по умолчанию пропускаются; флаги меняются в настройках.
Включение Members-only не предоставляет доступ к закрытым материалам.

Состояние сохраняется до и после каждого объекта; повторная обработка не
создаёт новые ID/номера. Update добавляет только новые ID. Новая обработка
архивирует предыдущее состояние. Экспорт:

- `UMD_URL.txt`: только URL, совместимые с 4K Video Downloader.
- `UMD_META.txt`: постоянные номера и поля `title=`, `original title=`, `overview=` без кавычек.
- `UMD_META.json`: метаданные, их происхождение и история.

Переводчики, AI и Jellyfin остаются будущими этапами. Авторизация, пользовательские
cookies и обход ограничений не реализованы. YouTube может менять DOM или ограничивать
доступ. Между вкладками канала без дат сортировка приблизительная.

## Настройки и диагностика

Настройки сохраняются кнопкой **Сохранить настройки**. Новые задачи используют
сохранённые значения; активные задачи сохраняют собственный снимок параметров.
Встроенные инструменты выбираются автоматически; можно указать свои пути.
**Проверить окружение** проверяет инструменты, Chromium и доступность каталогов.
Логи доступны кнопкой **Открыть логи**.

Для скриптов и диагностики предусмотрен `UMD-console.exe`:

```powershell
.\UMD-console.exe --version
.\UMD-console.exe --check-environment
.\UMD-console.exe --self-test
.\UMD-console.exe process "https://www.youtube.com/@jawed/videos"
.\UMD-console.exe resume
.\UMD-console.exe update
.\UMD-console.exe retry
```

`UMD.exe --data-dir "D:\UMD\separate-task"` открывает GUI с независимыми данными.
При повреждении JSON приложение сохраняет исходный файл; перед восстановлением
сделайте копию и проверьте `.bak`.

## Разработка и сборка

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install --editable ".[dev,build]"
.\.venv\Scripts\python.exe scripts/provision_tools.py
$env:PLAYWRIGHT_BROWSERS_PATH="0"
.\.venv\Scripts\python.exe -m playwright install chromium
.\.venv\Scripts\python.exe main.py
.\.venv\Scripts\python.exe -m pytest tests
.\.venv\Scripts\python.exe scripts/build_windows.py --version 0.1.0b2 --tag v0.1.0-beta.2
```

Нужен Windows x64 Python 3.12. `release-dist/` содержит ZIP, build manifest и SHA256.
Builder проверяет тесты, оба EXE, версию, окружение и настоящий запуск GUI.
В `build/gui-verification/` сохраняются JSON проверки и снимок окна.

`master` — разработка бет; stable-команда продвигает последнюю проверенную бету
в `main`, собирает и публикует полноценный релиз. `VERSION` между бетами неизменен.
