# UMD
UMD - Universal Media Downloader | Универсальный загрузчик медиаконтента

Репозиторий нового Python-проекта. Рабочая ветка — `master`.

GitHub Actions: **Start work**, **Update master**, **Publish release or beta**,
**CI**. Уведомления используют секреты Telegram, настроенные в репозитории.

Каждый спринт выпускает бету текущей версии (`v0.1.0-beta.N`) до ручной команды
стабильного релиза (`v0.1.0`). После релиза можно удалить беты этой версии
и повысить номер в `VERSION`.

Инструкции запуска, правила версий и подключение Python-сборки:
[docs/RELEASES.md](docs/RELEASES.md).
